# 背景美术风格规范

> 所有背景图（工作包 01）必须按这份规范制作。第 7 节的数值由 `pnpm check:handoff` 自动检查，不达标的图会被拒收。

## 0. 定位

**透明感・高明度（ハイキー）的日系插画，画面以天空和空气为主角，角色是唯一的视觉焦点。**

参照对象是轻小说封面和插画网站上「透明感」标签下的作品，**不是**动画电影截图，也不是 AI 壁纸。画面要让人感觉「亮、轻、通透、安静」，毛玻璃卡片压上去以后依然干净。

## 2. 参考图

- **正面参考**：从插画网站按 `透明感` `青空` `ハイキー` `空` 这几个标签，挑 5–8 张**整体很亮、天空占画面一半以上、背景简单、只有一个角色**的作品，放进 `handoff/codex/input/style-refs/`，每张旁边写一个同名 `.md` 说明：取它的「色」「光」「构图」中的哪一项。只学方法，不复制画面。
- **反面参考**：`input/style-refs/negative/codex-try1.png` 是第一次生成的结果，**不要做成这样**。问题见同目录的 `codex-try1.md`。
- 每次生成前先用 `node handoff/codex/scripts/style-metrics.mjs <参考图>` 测一下正面参考，确认它们本身符合第 7 节的数值；不符合的参考图不要用。

## 3. 明度构成（Value structure）

先定明暗，再上色。画面按明度分三档，面积比例固定：

| 明度档 | 范围（0 黑 – 1 白） | 面积 | 用在哪 |
| --- | --- | --- | --- |
| 高 | 0.80–0.97 | 约 70% | 天空、云、远景、光照面 |
| 中 | 0.55–0.80 | 约 25% | 角色的阴影面、栏杆、近景 |
| 低 | 0.25–0.55 | ≤ 5% | 只允许出现在角色身上：瞳孔、线稿、深色服饰 |

- 全图不出现纯黑（< 0.15）。纯白只用在云的亮部和高光。
- 内容区（会被文章卡片盖住的区域）里不允许出现低明度。

| 用途 | 色号 | 说明 |
| --- | --- | --- |
| 天顶 | #BFDDF5 | 天空最上方，最「蓝」的地方，饱和度也只有约 0.22 |
| 天空中段 | #DCEDFA | |
| 地平线 | #F4F8FC | 接近白，表现空气的厚度 |
| 云亮部 | #FFFFFF | |
| 云暗部 | #D5DFF0 | 偏蓝紫，不用灰色 |
| 暖光 | #FFF4E0 | 阳光照到的地方叠一层 |
| 远景建筑 | #CAD9E8 | 一个颜色、一个明度，像剪影 |
| 阴影 | #B8C2DE | 所有阴影偏蓝紫，不用灰或黑 |

| --- | --- |

| 天空中段 | #3F4A6E |
| 地平线 | #7A7FA3 |

### 规则

- 角色的固有色（发色、瞳色、服装、饰品）以参考图为准，不受上面色板限制，但要叠加场景的光色（白天偏暖、夜晚偏冷）。
- 全图色相集中在蓝到蓝紫一带，暖色只用于光，角色的瞳色等是唯一允许的高饱和点缀。
- 不出现青色（cyan）调的天空、荧光色、霓虹色。

## 5. 疏密（情報量）分区

画面细节要按区域分配，眼睛会被「密」的地方吸引，所以只有角色那里能「密」。

| 区域 | 疏密 | 允许出现 | 不允许出现 |
| --- | --- | --- | --- |
| 角色及身边 10% | 密 | 角色的全部细节、栏杆、身边少量花草 | — |
| 角色所在一侧的近景 | 中 | 栏杆延伸、地面 | 脚手架、藤蔓、管道 |
| 内容区（横屏中间偏左、竖屏下方） | 疏 | 渐变天空、2–3 团柔边积云、地平线上一条浅色远景剪影 | 电线杆、电线、水塔、窗格、招牌、成片楼群、飘落物 |
| 地平线远景 | 疏 | 一个明度的建筑和山的剪影 | 窗户、细节、清晰的边缘 |

## 6. 光与空气

- **主光**：一个光源。白天是左上方的柔和阳光（顺光偏侧光），夜晚是左上方的月光。
- **角色**：受光面亮，阴影面偏蓝紫；背光一侧加一道细的边缘光（白天暖白，夜晚冷蓝），让角色从天空里分离出来。
- **光晕**：高光处加轻微的光晕（ディフュージョン），整体像隔着一层很薄的雾。不要镜头光斑、光线条纹、色差。
- **空气透视**：分三层，越远越亮、越淡、越模糊。

| 层 | 对比度 | 饱和度 | 边缘 |
| --- | --- | --- | --- |
| 近景（角色、栏杆） | 完整 | 角色固有色 | 清晰 |
| 中景（如有） | 降一半 | 降一半 | 稍柔 |
| 远景（城市、山） | 很低，几乎融进天空 | 接近 0 | 模糊 |

## 7. 量化指标（自动检查）

`pnpm check:handoff` 会把每张背景图缩放到宽 1280px 后计算下面这些值，任何一项不达标就报错。单张图可以用 `node handoff/codex/scripts/style-metrics.mjs <图片> day|night` 自测。

**区域划分**：横屏的内容区是水平 20%–72%、垂直 40%–100%，角色区是水平 70%–100%；竖屏的内容区是垂直 38%–100%，角色区是垂直 0%–35%。

| 指标 | 白天版 | 夜晚版 | 第一次生成的图（不合格） |
| --- | --- | --- | --- |
| 全图平均饱和度 | ≤ 0.25 | ≤ 0.35 | 0.261 |
| 全图饱和度第 90 百分位 | ≤ 0.45 | ≤ 0.55 | 0.594 |
| 全图平均明度 | ≥ 0.72 | 0.20–0.45 | 0.669 |
| 内容区第 5 百分位明度 | ≥ 0.60 | — | 0.407 |
| 内容区细节密度（边缘像素占比） | ≤ 0.04 | ≤ 0.04 | 0.225 |
| 天空平均饱和度 | ≤ 0.30 | — | 0.414 |
| 角色区细节 ÷ 内容区细节 | ≥ 2 | ≥ 2 | 1.4 |

## 8. 构图与镜头

- **镜头**：略微仰视（アオリ，约 10–15°），让角色衬在天空前面，地平线压低。
- **地平线**：横屏在画面高度 85% 左右；竖屏在 90% 左右。地平线以下只有一条很窄的浅色远景。
- **景别**：膝上（ニーショット），角色高度占画面 60–75%（横屏）或画面宽度的 70%（竖屏）。
- **角色位置**：横屏在右侧三分线以右（水平 70%–95%）；竖屏在顶部（垂直 3%–35%）。
- **视线方向**：角色的脸和视线朝向内容区（横屏朝左，竖屏朝下或朝左下），把观众的视线引向文章。
- **留白**：内容区就是留白，只有天空和云。

## 9. 画法

| 对象 | 画法 |
| --- | --- |
| 角色 | アニメ塗り：赛璐璐分色，阴影交界处有柔和渐变；彩色线稿（色トレス），线条细；高光少而准 |
| 天空 | 平滑渐变，无笔触；积云柔边，云的暗部用蓝紫色 |
| 远景 | 剪影化，一个明度、一个颜色，不画窗户 |
| 栏杆和近景 | 简化形体，少量阴影，不画锈迹和污渍 |
| 质感 | 不加纸纹、噪点、颗粒；整体干净 |

## 10. 禁止清单

这些都是 AI 生成图最常见的问题，出现任何一项就重做：

- 漫天飘落的羽毛、花瓣、光点、气泡
- 青色调、高饱和的天空；HDR 感的强对比
- 内容区里的电线杆、电线、水塔、窗格、密集楼群
- 画面边缘堆满植物、藤蔓、脚手架、铁架
- 镜头光斑、光线条纹、色差、暗角
- 和主光方向矛盾的阴影
- 文字、招牌、水印、签名、Logo、霓虹
- 多余的人物、动物；手指、五官崩坏
- 改变角色的发型、服装、饰品
