# 角色资料放这里

| 文件 | 必需 | 要求 |
| --- | --- | --- |
| `character/fullbody.png` | 是 | 角色基准立绘（日光版，膝上构图，透明背景，1024×1536）。已放好，来自工作包 04 |
| `character/fullbody-night.png` | 否 | 同一张的夜间打光版，只用来对照阴影色 |
| `character/palette.md` | 是 | 发色、瞳色、服装主色、饰品色，各写一个色号；不知道就写「从图上取」 |
| `license.md` | 是 | 这张图的来源和授权：能否用于网站、能否拆分做动画、能否给 AI 生成衍生图 |
| `brief.md` | 建议 | 场景、角色名、性格、口癖、台词；模板已经放好了 |
| `character/turnaround-front.png` `-side.png` `-back.png` | 建议 | 三视图，保持生成图里造型一致 |
| `character/expressions/*.png` | 建议 | 表情参考，文件名用英文：`happy` `surprised` `shy` `angry` `sleepy` `thinking` |
| `style-refs/negative/*` | 参考 | 反面例子：之前不合格的生成结果，不要往这个方向画 |

图片格式用 PNG 或 JPG。文件名只用英文、数字和连字符。
