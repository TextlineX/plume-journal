# 角色配色

从基准立绘 `fullbody.png`（日光版，透明底 1024×1536）取样，k-means 聚类 + 局部中值。数值是绘画里的平均色，画 Q 版时按这个方向走，不要逐像素对色。

| 部位 | 色号 | 说明 |
| --- | --- | --- |
| 发色（亮部） | #FAF5F5 | 近白，偏暖 |
| 发色（中间调） | #ECE1EA | 带一点粉紫 |
| 发色 / 羽毛（阴影） | #D8CEE0 → #B6A7C0 | 阴影偏薰衣草紫，不要用灰 |
| 瞳色 | #B15468 | 红玫瑰色，高光偏粉 |
| 连衣裙 | #FAF5F5 / 阴影 #CEBBCA | 白色缎面，腰带同色 |
| 长手套 | #493F44 | 黑色，带白色蔓草蕾丝渐变到上臂 |
| 内层纱裙 | #493F44 | 黑色半透明纱，有细小亮点 |
| 饰品 | 金色 #D4B06A 左右 | 颈部星形吊坠、裙侧菱形吊坠 |
| 线稿 | #6C5E66 | 暖灰紫，不用纯黑 |

夜间版 `fullbody-night.png` 是同一张图的薰衣草夜打光，只用来对照阴影色，Q 版一律按日光版配色画。
